# Nachiket Dhakad: Portfolio

Static portfolio (HTML + CSS + JS, no build step). Design: 8B template (MIT).

## GitHub Pages par daalna
1. Repo banao: `YOUR-USERNAME.github.io`
2. Is folder ki saari files (index.html, css/, LICENSE, CREDITS.md) upload karo.
3. Settings → Pages → Source: `main` / root → Save.
4. Site: https://YOUR-USERNAME.github.io

## Apni details badalna (index.html mein Ctrl+F karo)
- `your-email@example.com` -> apna Gmail
- `YOUR-USERNAME` -> apna GitHub username
